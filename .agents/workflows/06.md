# 06-prag-local-fast-async

## Description
Refactors the P.R.A.G. architecture to a local-only, ultra-fast asynchronous pipeline. It uses Playwright Network Interception, local `mlx-whisper` (multilingual for Hindi/Hinglish) for audio transcription, and a local text LLM (Qwen 2.5 / Llama 3.1) via LM Studio. Execution is pipelined asynchronously so the browser does not freeze while waiting for the LLM.

## Steps

1. **Update Dependencies (`requirements.txt`)**
   - Update `requirements.txt` to include:
     ```text
     playwright
     playwright-stealth
     mlx-whisper
     ffmpeg-python
     aiohttp
     pandas
     ```
   - Note: We drop `google-genai` and `yt-dlp`. 
   - Ensure the user runs `pip install -r requirements.txt` and `playwright install chromium`.
   - Ensure the user installs `ffmpeg` on their Mac (`brew install ffmpeg`).

2. **Update Database Schema (`database/db.py`)**
   - Ensure `reels.db` schema contains:
     - `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
     - `timestamp` (DATETIME DEFAULT CURRENT_TIMESTAMP)
     - `reel_url` (TEXT)
     - `caption` (TEXT)
     - `transcript` (TEXT)
     - `alignment_score` (REAL)
     - `like_count` (INTEGER)
     - `comment_count` (INTEGER)
     - `action_taken` (TEXT)
   - Update `log_reel_event()` to accept and persist these parameters using asynchronous DB calls (or `sqlite3` wrapped in thread).

3. **Build the Local Perception Engine (`perception/local_evaluator.py`)**
   - Create `perception/local_evaluator.py`:
     - **Audio Extraction:** Implement `extract_audio(video_path: str, audio_path: str = "temp_audio.mp3")`. Use `ffmpeg-python` to strip the audio track locally (takes ~50ms).
     - **Multilingual Transcription:** Implement `transcribe_audio(audio_path: str) -> str`. 
       - Import `mlx_whisper`.
       - Use the model `mlx-community/whisper-large-v3-turbo` which natively supports Hindi, English, and Hinglish natively on Apple Silicon.
     - **Local LLM Scoring (Async):** Implement an async function `evaluate_alignment_async(transcript: str, caption: str, target_bias: str) -> dict`.
       - Use `aiohttp.ClientSession()` to POST to the local LM Studio endpoint `http://127.0.0.1:1234/v1/chat/completions`.
       - Instruct the text model to evaluate the `transcript` and `caption` against the `target_bias` and return JSON `{"alignment_score": <float>, "reasoning": "<str>"}`.

4. **Build the Asynchronous Browser Controller (`automation/browser_driver.py`)**
   - Rewrite using `playwright.async_api` and `asyncio`:
     - `async def init_browser(...)`: Launch persistent context.
     - Implement humanized async actions: `async def scroll_next(page)`, `async def like_reel(page)`.
     - Implement `async def capture_active_reel_and_metadata(page)`:
       - Attach a one-time network listener (`page.on("response")`) to intercept the CDN `.mp4` stream and save to `temp_reel.mp4`.
       - Read DOM metadata (caption, likes, etc.) asynchronously.

5. **Assemble the Pipelined Orchestration Loop (`main.py`)**
   - Refactor `main.py` into a fully asynchronous event loop:
     1. Initialize database and `playwright.async_api` browser.
     2. Navigate to `https://www.instagram.com/reels/` and await user login if needed.
     3. Start the continuous `while True:` async loop:
        a. Await `capture_active_reel_and_metadata(page)` to get the `temp_reel.mp4` and `caption`.
        b. **Start the Background Task:** Use `asyncio.create_task()` to run the perception pipeline (audio extraction -> `mlx-whisper` transcription -> LM Studio LLM scoring) in the background.
        c. **Foreground Baseline Watch:** Await `asyncio.sleep(3.0)` to let the browser play the video naturally for at least 3 seconds, mimicking a human deciding if they like the video.
        d. Await the background perception task to resolve and get the `alignment_score`.
        e. Pass the score to `decide_action()` to get remaining watch time and action (Like/Skip).
        f. Await the remaining watch time. 
        g. Execute `like_reel(page)` if designated.
        h. Log to SQLite.
        i. Scroll next and clean up temp files.
