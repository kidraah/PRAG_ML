## Steps

1. **Build Fast-Path Heuristic Filter (`perception/heuristics.py`)**
   - Create `perception/heuristics.py`:
     - Define a curated set of `EXCLUDE_KEYWORDS` (e.g., cooking, recipes, gaming, pubg, makeup, beauty, skincare, fashion, ootd, cricket, ipl, dance, bollywood, cinema, standup comedy, fitness, workout).
     - Implement `fast_heuristic_check(caption: str) -> bool`:
       - Normalize caption text (lowercase, remove excess punctuation).
       - If any excluded keyword or hashtag is found, return `False` (Instant Reject).
       - If no obvious negative topic is detected, return `True` (Proceed to deep audio/LLM evaluation).

2. **Build Continuous Network Buffer & Lookahead Interceptor (`automation/browser_driver.py`)**
   - Update `automation/browser_driver.py` using `playwright.async_api`:
     - Maintain an in-memory buffer / dictionary `video_stream_cache = {}` that records incoming `.mp4` chunks from `cdninstagram.com` keyed by request URL or sequence.
     - Implement `attach_continuous_stream_listener(page)`:
       - Keep a continuous `page.on("response")` listener running in the background.
       - Whenever a CDN video response arrives, stream and cache the bytes in memory/temp storage so pre-fetched reels ($N+1$) are available immediately.
     - Implement `get_active_reel_dom(page) -> dict`:
       - Quickly read `current_url`, `caption`, `like_count`, and `comment_count` from the active viewport.
     - Implement high-speed vs. humanized gestures:
       - `fast_skip(page)`: Executes an immediate swipe/drag up within `random.uniform(0.35, 0.65)` seconds.
       - `extended_watch_and_like(page, duration: float)`: Plays video for `duration` seconds, performs humanized double-click with random coordinate offset, and executes a natural scroll.

3. **Build the Lookahead Evaluation Manager (`agent/lookahead.py`)**
   - Create `agent/lookahead.py`:
     - Implement an asynchronous worker `pre_evaluate_next_reel(video_bytes, caption, target_bias) -> dict`:
       - Saves bytes to `temp_next_reel.mp4`.
       - Extracts audio with `ffmpeg` (~50ms).
       - Transcribes using `mlx-whisper` (`whisper-large-v3-turbo`).
       - Hits local LM Studio endpoint (`http://127.0.0.1:1234/v1/chat/completions`) asynchronously via `aiohttp`.
       - Returns `{"alignment_score": float, "reasoning": str, "transcript": str}`.

4. **Update Decision Policy & Timings (`agent/bandit.py`)**
   - Update `agent/bandit.py`:
     - `decide_timing_and_action(alignment_score: float, heuristic_pass: bool) -> tuple[str, float]`:
       - If `heuristic_pass is False`: Return `("INSTANT_SKIP", random.uniform(0.35, 0.65))`
       - If `alignment_score < 0.40`: Return `("FAST_SKIP", random.uniform(0.50, 0.85))`
       - If `0.40 <= alignment_score < 0.75`: Return `("WATCH", random.uniform(4.0, 6.5))`
       - If `alignment_score >= 0.75`: Return `("LIKE_AND_WATCH", random.uniform(12.0, 18.0))`

5. **Assemble Lookahead Orchestration Loop (`main.py`)**
   - Refactor `main.py` with lookahead state tracking:
     - State variables: `pre_computed_score = None`, `next_reel_eval_task = None`.
     - Main execution loop:
       1. Extract DOM caption and URL for current reel ($N$).
       2. **Stage 1 — Heuristic Gate:** 
          - If `fast_heuristic_check(caption)` returns `False`:
            - Immediately execute `fast_skip(page)`.
            - Log event as `HEURISTIC_SKIP` and continue to next reel.
       3. **Stage 2 — Resolve Evaluation:**
          - If `pre_computed_score` exists from previous reel's lookahead:
            - Use existing score and metadata.
            - Clear `pre_computed_score`.
          - Else (Cold start / after fast skip):
            - Run quick local evaluation pipeline (`perception/local_evaluator.py`).
       4. **Stage 3 — Action Execution & Background Lookahead:**
          - Get action and duration from `decide_timing_and_action()`.
          - If action is `LIKE_AND_WATCH` (long dwell time 12–18s):
            - **Spawn Background Lookahead Task:** Intercept pre-fetched CDN buffer for Reel $N+1$ and start `pre_evaluate_next_reel()` in background.
            - Await remaining watch time and execute `like_reel(page)`.
            - Await background lookahead task to populate `pre_computed_score` for the upcoming reel.
          - If action is `FAST_SKIP`:
            - Sleep for minimal skip duration (< 0.85s).
            - Advance immediately.
       5. Persist reel metadata, transcripts, and scores into `reels.db`.
       6. Advance to next reel with `scroll_next(page)`.
