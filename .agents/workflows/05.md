## Steps

1. **Update Dependencies (`requirements.txt`)**
   - Update `requirements.txt` to include:
     ```text
     playwright
     playwright-stealth
     google-genai
     requests
     pandas
     ```
   - Note: We removed `yt-dlp`, `opencv-python`, and `mlx-whisper` since network interception and Gemini will handle the media and transcription native processing.
   - Run `pip install -r requirements.txt` and execute `playwright install chromium` via the terminal tool.

2. **Update Database Schema (`database/db.py`)**
   - Update `reels.db` schema initialization to ensure the `reels` table contains:
     - `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
     - `timestamp` (DATETIME DEFAULT CURRENT_TIMESTAMP)
     - `reel_url` (TEXT)
     - `caption` (TEXT)
     - `sensory_summary` (TEXT)
     - `alignment_score` (REAL)
     - `like_count` (INTEGER)
     - `comment_count` (INTEGER)
     - `action_taken` (TEXT)
   - Update `log_reel_event()` to accept and persist these parameters.

3. **Build the Playwright Engine & Interceptor (`automation/browser_driver.py`)**
   - Create `automation/browser_driver.py` using `playwright.sync_api` and `playwright_stealth`:
     - Implement `init_browser(user_data_dir: str = "./browser_profile")`:
       - Launch a persistent context (`chromium.launch_persistent_context`) with viewport `1280x800` and `headless=False`.
       - Apply `stealth_sync(page)`.
       - Return `(browser_context, page)`.
     - Implement humanized actions using `random.uniform`:
       - `scroll_next(page)`: Use mouse events to simulate a natural drag-up scroll, rather than instant keystrokes, with a random delay.
       - `like_reel(page)`: Locate the video container's bounding box and execute a double-click (`mouse.dblclick()`) at randomized X/Y offsets near the center.
     - Implement the Network Interceptor `capture_active_reel(page) -> dict`:
       - Attach a `page.on("response")` listener.
       - If `response.url` contains `cdninstagram.com` and `content-type` is video/mp4, save the buffered bytes to `temp_reel.mp4`.
       - Wait 2–3 seconds for the buffer to fill naturally as the video starts playing.
       - Read the current `reel_url`, `caption`, `like_count`, and `comment_count` directly from the DOM using Playwright locators with safe fallback values.
       - Remove the network listener.
       - Return the dictionary of DOM metadata and the path to `temp_reel.mp4`.

4. **Build the Two-Layer Evaluator (`perception/evaluator.py`)**
   - Rewrite `perception/evaluator.py`:
     - **Layer 1 (The Eyes & Ears - Gemini API):**
       - Implement `extract_sensory_data(video_path: str) -> str`.
       - Use the `google-genai` SDK `Client` object. 
       - Upload the video: `file = client.files.upload(file=video_path)`.
       - Generate content using the `gemini-1.5-flash` model (or latest available flash).
       - Provide a strictly neutral prompt: *"Transcribe the audio exactly. Describe what happens visually. List any text on screen. Do not evaluate, analyze, or score the video."*
       - Return the raw response text.
     - **Layer 2 (The Judgment Brain - Local LM Studio):**
       - Implement `evaluate_alignment(sensory_summary: str, caption: str, target_bias: str) -> dict`.
       - Construct an OpenAI-compatible text payload for `http://127.0.0.1:1234/v1/chat/completions`.
       - System message: Specify strict JSON output matching `{"alignment_score": <float 0.0 to 1.0>, "reasoning": "<brief summary>"}`.
       - User message: Pass the `TARGET_BIAS`, the `caption`, and the `sensory_summary` generated by Gemini.
       - Return the parsed JSON block, with a fallback `{"alignment_score": 0.0, "reasoning": "Error"}` in a `try/except` block if parsing fails.

5. **Update Decision Bandit (`agent/bandit.py`)**
   - Update `decide_action(alignment_score: float) -> tuple[str, float]`:
     - High alignment (>= 0.75): Return `("LIKE_AND_WATCH", random.uniform(12.3, 22.7))`
     - Moderate alignment (0.40 - 0.74): Return `("WATCH", random.uniform(4.5, 8.2))`
     - Low alignment (< 0.40): Return `("SKIP", random.uniform(1.2, 2.8))`

6. **Assemble the P.R.A.G. Orchestration Loop (`main.py`)**
   - Refactor `main.py` into a unified execution loop:
     1. Initialize database and launch persistent browser controller.
     2. Navigate to `https://www.instagram.com/reels/`.
     3. If not logged in, pause execution, prompt the user in the terminal to manually complete the login in the browser, and hit `Enter` to resume.
     4. Loop continuously:
        a. Call `capture_active_reel(page)` to intercept the CDN buffer and read DOM metrics.
        b. Pass `temp_reel.mp4` to Layer 1 `extract_sensory_data()` to get the neutral description.
        c. Pass the summary and DOM caption to Layer 2 `evaluate_alignment(..., TARGET_BIAS)`.
        d. Pass the score to `decide_action()` to get the dynamic watch time.
        e. Sleep for the assigned watch duration.
        f. Execute `like_reel(page)` if designated by the policy.
        g. Persist all metrics and actions to `reels.db`.
        h. Delete `temp_reel.mp4` safely.
        i. Advance to next reel with `scroll_next(page)`.
